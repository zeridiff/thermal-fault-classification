Fixed exploratory filter comparison; no retraining. Noise is added to resized RGB values in [0,1], then filtered, then ImageNet-normalised. Each filter receives the same corruption for each sample/repeat. Clean images are also tested through every filter. Positive change means improvement over no filter. Error bars are standard deviations across corruption repeats, not training runs or confidence intervals. Comparing filters on these test data is exploratory; choosing and claiming a final best filter needs validation-based selection and independent confirmation. Source images and models are unchanged.
